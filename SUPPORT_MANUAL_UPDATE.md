# SyncSpace Support Manual Update

The home page Support section has been expanded into an interactive user manual.

## Added

- Eight-step SyncSpace quick-start manual
- Animated step navigation and detail panel
- Previous/next manual controls and progress indicator
- Sharp-edged interface boxes
- System workflow overview
- Troubleshooting FAQ section
- Improved support contact card
- Responsive mobile and desktop layouts
- Reduced-motion accessibility support through the existing global CSS rules

## Main modified file

`frontend/app/page.tsx`

## Run locally

```bash
cd frontend
npm install
npm run dev
```

Open `http://localhost:3000` and scroll to the Support section.
